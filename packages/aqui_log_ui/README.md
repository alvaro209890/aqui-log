# Pacote `aqui_log_ui`

Tema e componentes compartilhados dos apps Flutter. O laranja da marca não deve
substituir cores semânticas de sucesso, alerta, erro ou status.

```bash
cd packages/aqui_log_ui
flutter pub get
flutter analyze
flutter test
```
