# Pacote `aqui_log_core`

Cliente HTTP e modelos compartilhados pelos apps Flutter.

```bash
cd packages/aqui_log_core
dart pub get
dart analyze
dart test
```

Preserve compatibilidade de contratos e o fallback de `notes`. Mudanças de API
devem atualizar também `docs/03-referencia/02-API.md` e os testes dos dois apps.
